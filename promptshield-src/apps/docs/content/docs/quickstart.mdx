title: Quickstart

By the end of this guide, one public gateway will accept OpenAI-compatible
traffic at `/v1`, PromptShield will enforce policy inline, and Bifrost will own
provider routing behind it.

## 1. Configure the product

```bash
cp .env.example .env
```

Set the required product secrets in `.env`:

```bash
POSTGRES_PASSWORD=<database-password>
BETTER_AUTH_SECRET=<32-plus-character-secret>
PROMPTSHIELD_ENGINE_API_KEY=<engine-shared-secret>
AUDIT_INGEST_SECRET=<audit-shared-secret>
```

Provider API keys, model routes, fallback, and key pools are configured in
Bifrost. Keep PromptShield pointed at Bifrost as its OpenAI-compatible upstream.

## 2. Start the gateway

```bash
docker compose up -d --build
```

Nginx is the public entry point. PromptShield Gateway, PromptShield Engine,
Dashboard API, Dashboard Web, and Bifrost are internal Compose services.

## 3. Verify health

```bash
curl -s http://localhost/health
```

Open the dashboard at `http://localhost/`. If your workstation is on an allowed
admin network, open Bifrost at `http://localhost/bifrost/` to configure provider
credentials and routing.

## 4. Send a request

Point your app at `http://localhost/v1`. The API is OpenAI-compatible, so
existing client code usually only needs the base URL changed.

```bash
curl -s -X POST http://localhost/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model": "gemini-2.0-flash", "messages": [{"role": "user", "content": "Say hello"}]}'
```

## 5. Test detection

Send a prompt containing a leaked secret:

```bash
curl -s -X POST http://localhost/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gemini-2.0-flash",
    "messages": [{
      "role": "user",
      "content": "Why is my app broken?\n\nOPENAI_API_KEY=sk-proj-abc123\nDB_URL=postgres://admin:pass@prod.db/app"
    }]
  }'
```

The request is blocked before it reaches Bifrost or any provider.

## Services reference

| Surface | Address | Notes |
| ------- | ------- | ----- |
| Product gateway | `http://localhost` | Public dashboard, health, and `/v1` inference |
| Public inference | `http://localhost/v1` | PromptShield policy first, then Bifrost routing |
| Bifrost admin | `http://localhost/bifrost/` | Admin-only provider/router control plane |
| Internal services | Compose network only | PromptShield Gateway, Engine, Dashboard API, Dashboard Web, Bifrost |
