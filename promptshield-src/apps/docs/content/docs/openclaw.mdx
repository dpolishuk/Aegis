---
title: OpenClaw
description: Run PromptShield as the gateway between OpenClaw and your LLM provider.
---

OpenClaw supports custom providers via `openclaw.json`. Point it at the product
gateway and every request gets scanned, rate limited, and logged before Bifrost
routes it to a provider.

```
OpenClaw -> Product /v1 -> PromptShield -> Bifrost -> LLM provider
```

## 1. Configure the product

In the combined product, configure provider credentials in Bifrost and point
PromptShield at Bifrost:

```bash
PROMPTSHIELD_PROVIDER=openai-compatible
PROMPTSHIELD_OPENAI_COMPATIBLE_UPSTREAM_URL=http://bifrost:8081/v1
```

Start the product from the repository root:

```bash
docker compose up -d --build
```

## 2. Configure OpenClaw

Edit `~/.openclaw/openclaw.json`:

```json
{
  "models": {
    "providers": {
      "promptshield": {
        "baseUrl": "http://localhost/v1",
        "apiKey": "local",
        "api": "openai-completions"
      }
    }
  },
  "agents": {
    "defaults": {
      "model": {
        "primary": "promptshield/claude-sonnet-4-5"
      }
    }
  }
}
```

`apiKey` is a placeholder for local client compatibility. Provider credentials
are stored in Bifrost, not in OpenClaw or PromptShield.
