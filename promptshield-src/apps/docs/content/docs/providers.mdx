---
title: Provider Setup
description: Configure provider routing and credentials in Bifrost for the combined gateway product.
---

In the combined PromptShield + Bifrost product, provider routing and provider
API keys belong to Bifrost. PromptShield stays inline before provider routing and
forwards allowed OpenAI-compatible traffic to Bifrost.

## Production topology

```text
Client → PromptShield /v1 → Bifrost /v1 → LLM provider
```

Set PromptShield to a single OpenAI-compatible upstream that points at Bifrost:

```bash
PROMPTSHIELD_PROVIDER=openai-compatible
PROMPTSHIELD_OPENAI_COMPATIBLE_UPSTREAM_URL=http://bifrost:8081/v1
```

Do not store OpenAI, Anthropic, Gemini, or other provider keys in PromptShield
environment files for the combined product. Add those keys and model routes in
the Bifrost admin UI or through your approved secret-management workflow.

## Bifrost responsibilities

- Provider credentials and key pools
- Provider fallback order
- Model-to-provider routing
- Router governance and provider-level controls

## PromptShield responsibilities

- Request policy enforcement before Bifrost receives traffic
- PII and secret detection
- Audit, metrics, rate limits, and token budgets
- Response scanning when enabled
