---
title: Engine
description: PromptShield detection engine inside the combined gateway product.
---

The detection engine is an internal service in the combined product. PromptShield
Gateway calls it before forwarding allowed requests to Bifrost.

```text
Client -> Nginx /v1 -> PromptShield Gateway -> PromptShield Engine
                                      |
                                      v
                                  Bifrost /v1
```

The engine is not a public API surface. It listens only on the Compose network
and requires the shared `PROMPTSHIELD_ENGINE_API_KEY` in production.

## Configure

Set the same secret for the gateway, dashboard, and engine through the root
product environment:

```bash
PROMPTSHIELD_ENGINE_API_KEY=<engine-shared-secret>
```

Compose wires the internal URLs:

```bash
PROMPTSHIELD_ENGINE_URL=http://promptshield-engine:4321
ENGINE_URL=http://promptshield-engine:4321
```

## Health

The production Compose healthcheck calls the engine readiness endpoint on the
internal network. Operators should verify the public product gateway instead:

```bash
curl -s http://localhost/health
```

## Authentication

Do not disable engine authentication in production. Keep
`PROMPTSHIELD_ALLOW_UNAUTH=false` and use a strong
`PROMPTSHIELD_ENGINE_API_KEY`.
