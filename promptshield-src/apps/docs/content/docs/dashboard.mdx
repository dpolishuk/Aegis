The dashboard is part of the combined gateway product. It manages PromptShield
security policy, audit visibility, gateway/engine health, and links operators to
Bifrost for provider routing and provider API keys.

</figure>

## What It Does

- Edit `policy.yaml`; changes hot-reload into the gateway.
- Browse blocked requests and detected entity types.
- Configure PromptShield security settings such as engine URL, gateway route,
  and policy path.
- Open Bifrost for provider credentials, model routing, key pools, fallback, and
  router governance.
- View gateway, detection engine, and router health.

Provider credentials and model routing are not configured in PromptShield. They
belong to Bifrost.

## Run

Start the full product from the repository root:

```bash
docker compose up -d --build
```

The dashboard is available through the product gateway at `http://localhost/`.
Its API and web services are internal Compose services behind Nginx.

## Admin Access

Dashboard config mutations require a signed-in user whose email is listed in
`CONFIG_ADMIN_EMAILS`.

```bash
CONFIG_ADMIN_EMAILS=admin@yourcompany.com
```

There is no default config-admin email. Set this explicitly for production.

## Policy File Path

The dashboard reads and writes the mounted product policy file:

```bash
POLICY_FILE_PATH=/policy/policy.yaml
```

Use [Deployment](/docs/deployment) for the production startup and verification
flow.
